Windows计划任务注册

schtasks 是 Windows 系统自带的命令行工具，功能与图形化的“任务计划程序”完全一致，让你可以直接在终端里创建、修改、查询和删除计划任务。

它的基本命令结构如下：

其中，最常用的几个操作是 create（创建）、query（查询）、change（修改）、run（立即运行）和 delete（删除）。

📋 核心命令与通用参数

schtasks /create - 创建计划任务

这是最核心、最复杂的命令。以下是创建任务时最常用到的参数：

参数 说明 示例
/tn 任务名称（必填）。不能和已有任务重名。 /tn "MyTask"
/tr 要运行的程序或命令（必填）。需要填写完整的路径。 /tr "C:\Scripts\backup.bat"
/sc 计划频率（必填）。这是最重要的参数之一。 /sc daily (每天)
/mo 运行间隔。与 /sc 配合使用，指定每几天/几周等。 /mo 2 (每2天/周/月)
/d 在一周或一月中的特定几天运行。 /d MON,WED,FRI (周一、三、五)
/d 1,15 (每月1号和15号)
/st 开始时间。24小时制。 /st 14:30 (下午2:30)
/sd 开始日期。 /sd 2024/12/01
/ru 任务运行所用的账户。 /ru SYSTEM (系统账户)
/ru "DOMAIN\User"
/rp /ru 指定账户的密码。如果使用 SYSTEM 账户则不需密码。 /rp "MyPassword"
/f 强制创建。如果任务已存在，则强制覆盖。 /f
/rl 设置任务运行级别。HIGHEST 表示以最高权限运行。 /rl HIGHEST

schtasks /query - 查询计划任务

用于查看已经创建的任务。

参数 说明 示例
/tn 指定要查询的任务名称。如果不加，则列出所有任务。 /tn "MyTask"
/fo 输出格式。可设为 TABLE(表格)、LIST(列表) 或 CSV。 /fo CSV
/v 显示详细属性。包含更多高级信息。 /v
/nh 不显示列标题。常与 /fo TABLE 或 /fo CSV 一起用。 /nh

其他常用命令

命令 说明 示例
schtasks /change 修改现有任务的属性。可以改 /tn、/tr、/ru 等。 schtasks /change /tn "MyTask" /ru "SYSTEM"
schtasks /run 立即运行指定的任务。忽略预设的排程。 schtasks /run /tn "MyTask"
schtasks /end 停止由任务启动的程序。 schtasks /end /tn "MyTask"
schtasks /delete 删除计划任务。 schtasks /delete /tn "MyTask" /f

💡 使用示例与场景

1. 创建每天定时关机的任务

这个例子会创建一个名为 DailyShutdown 的任务，在每天23:30执行关机命令。

  • /tr "shutdown /s /f /t 0"：/s 是关机，/f 强制关闭应用，/t 0 是立即执行。
  • /sc daily /st 23:30：设置计划为每天 (daily) 的23:30开始。

2. 创建每周运行一次的维护脚本

这个例子会创建一个在每周日凌晨3点运行一个维护脚本的任务。

  • /sc weekly /d SUN：设置为每周 (weekly) 的周日 (SUN) 运行。
  • /ru SYSTEM：使用具有更高权限的系统账户 (SYSTEM) 来运行脚本，避免权限不足。

3. 查询并验证任务是否成功创建

使用 /query 可以查看任务状态。如果想看详细信息，可以加上 /v 和 /fo LIST 参数。

⚠️ 注意事项

  1. 管理员权限：执行 schtasks 来创建、修改或删除任务时，必须以管理员身份运行命令提示符或PowerShell，否则会提示“拒绝访问”。
  2. 任务名称唯一性：每个计划任务的名称 (/tn) 在系统中必须是唯一的。
  3. 引号使用：如果任务名称、路径或参数中包含空格，请务必使用英文双引号 " 将它们括起来。
  4. 编码问题：在某些系统上运行 schtasks /query 时，可能会遇到“无法加载列资源”的错误。这通常是CMD的代码页设置问题，可以先执行 chcp 437 将代码页切换到美国英语，查询完成后再用 chcp 936 切换回简体中文。

schtasks 的参数虽然多，但掌握 /create、/query 和 /delete 这几个核心参数，再配合 /sc、/tn、/tr、/st 这些常用选项，就能覆盖绝大部分的自动化需求了。
