安装

Linux 

1

sudo apt install tmux -y

Windows

原生Windows Terminal支持分屏功能，但是关闭窗口之后不能持久化，有个Rust写的wmux意在对标Linux的Tmux，不过还没用过

使用

快捷键

键位 功能
Ctrl + b 松开 % 左右分屏
Ctrl + b 松开 " 上下分屏
Ctrl + b 松开 方向键↑↓←→ 移动光标所在分窗
Ctrl + b 不松开 方向键↑↓←→ 移动所在分窗比例
Ctrl + b + z 当前分窗扩大到填满窗口
Ctrl + b 松开 x 关闭当前所在分窗
