Windows后台服务注册

windows提供的注册方法实在是太麻烦了，所以这里走一个第三方软件的注册方式：Non-Sucking Service Manager ，完全能看得出来这作者当年被Windows的服务注册给折磨成了啥…

此软件可通过winget安装，直接命令安装即可:winget install NSSM.NSSM

使用

操作 命令
注册服务 nssm install 服务名
启动服务 nssm start 服务名
停止服务 nssm stop 服务名
重启服务 nssm restart 服务名
查看状态 nssm status 服务名
修改配置 nssm edit 服务名
删除服务 nssm remove 服务名
注册之后会弹窗让你输入配置，配置完了之后就会自动注册成服务，如果想配置开机自启动之类的功能的话，就编辑服务来修改服务
