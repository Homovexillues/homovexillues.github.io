标签 Docker / 虚拟机

一个docker的container为[程序，环境]，而环境又是[操作系统，用户配置] 而操作系统又分为了[用户空间，内核空间]，应用程序运行在用户空间，而作为一个虚拟机，它不真的需要操作系统内核空间的部分，只需要阉割掉内核空间，只保留用户空间，就能构建出程序运行所需的环境

dockerfile就是写好了从系统开始到运行我所需的程序所需要的所有操作，定义了环境，创建文件夹，等等
