docker中的镜像，容器和仓库

  • 镜像

    镜像是一个只读的模板，可以用来创建容器

  • 容器

    容器是docker的运行环境，提供了一个独立的可移植的环境，可以在这个环境中运行应用程序，是一个运行实例

  • 仓库

    用来存储docker镜像的地方，用来管理和存储docker的镜像

镜像是比容器更抽象的东西，镜像就是食谱或者说建筑图纸，容器就是根据食谱和建筑图纸做出来的菜和盖出来的房子

docker使用client-server架构模式，Docker client和Docker Daemon之间通过Socket和RESTful API进行通信

Docker daemon即服务端的守护进程，负责管理Docker的各种资源

# 2026-08-07 首先用snap安装就不对，尽可能的跟着docker官方安装方式走
snap install docker

# 从Docker Compose文件中定义的服务所需的镜像从仓库中拉取镜像
docker-compose pull
# 用此命令来构建并自动创建或重建容器，然后启动它们，并建立它们之间的网络连接，-d表示以后台模式运行容器，不会占用终端的输出
docker-compose up -d
# 查看目前我所有的docker镜像
docker images
docker image ls
# 删除名字为my_image_id的镜像
docker rmi my_image_id
# 删除所有没有被使用的dockr镜像
docker prune -a
# 删除所有docker镜像
docker rmi $(docker images -q)
# 用docker scout来显示docker镜像的快速概览
docker scout quickview
# 查看所有容器的名字
docker ps -a
# 查看所有正在运行的容器的名字
docker ps
# 查看容器的日志信息
docker logs container_name
# 实时查看容器的日志信息
docker logs -f container_name
# 重启docker容器
docker restart container_name

# 导出镜像到文件
docker save -o xxx.tar xxx:xx
# 加载镜像
docker load -i xxx.tar
