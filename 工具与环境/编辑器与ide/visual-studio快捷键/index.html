Visual Studio快捷键

工具与环境 / 编辑器与IDE
创建 2024-04-03 修改 2026-07-06 字数 约 300 字  阅读 预计阅读 1 分钟
标签 Visual Studio / 快捷键
目录
  • 大小写
      • 小写 Ctrl+U
      • 大写 Ctrl+Shift+U
  • 选择
      • 选中所有相同单词 Alt+Shift+;
      • 选中多行光标 Shift+Alt+上/下
      • 整行移动 按住Alt+上下键可以将当前行或选中行上下移动
  • 复制和剪切
      • 复制当前行 Ctrl+D
      • 剪切/删除当前行 Ctrl+X
    • 资源解决方案管理器窗口 Ctrl+Alt+L
    • 终端界面 Ctrl+~
  • 跳转
      • 以单词为单位跳转 Ctrl+左键/Ctrl+右键
      • 跳转到指定行 Ctrl+G
      • 跳转到实现 F12
      • 跳转到定义 Shift+F12
      • 跳转到打开的文件 Ctrl+TAB
      • 跳转到文件开头或结尾 Ctrl+Home/End
      • 跳转到下一个，上一个Find F3/Shift F3
  • 展开
      • 折叠所有代码Ctrl+M+O
      • 展开所有代码Ctrl+M+L
  • 添加
    • #region代码块 手写#region然后Tab
    • 任意外侧代码 Ctrl+k+Ctrl+S
  • 重命名
      • 变量重命名 Ctrl+R+R
  • 剪切板
      • 展示历史剪切板 Ctrl+Shift+V
