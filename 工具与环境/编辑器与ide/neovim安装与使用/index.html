安装

Windows

在线安装 

1

winget install NeoVim

Linux

离线安装

直接安装预编译版本

1
2
3
4

curl -LO https://github.com/neovim/neovim/releases/latest/download/nvim-linux-x86_64.tar.gz
sudo rm -rf /opt/nvim-linux-x86_64
sudo tar -C /opt -xzf nvim-linux-x86_64.tar.gz
export PATH="$PATH:/opt/nvim-linux-x86_64/bin"

在线安装

直接用自带包管理器安装，不过要注意一下安装出来的版本可能会比较老

配置包

lazyvim

安装

Windows 

1

8

# required
Move-Item $env:LOCALAPPDATA\nvim $env:LOCALAPPDATA\nvim.bak
# 如果报错说找不到xxxx\nvim文件夹说明没做过配置
# optional but recommended
Move-Item $env:LOCALAPPDATA\nvim-data $env:LOCALAPPDATA\nvim-data.bak
git clone https://github.com/LazyVim/starter $env:LOCALAPPDATA\nvim
# 记得移除.git文件夹
Remove-Item $env:LOCALAPPDATA\nvim\.git -Recurse -Force

使用

键位

快捷键 功能描述
gd (Go Definition)跳转到光标所在的内容的定义位置
gr 查找所有引用
gc 注释/解注释选中的代码
<leader> + e 打开/关闭 `:Explore文件浏览器
Explore中 a 按 a（add），然后输入 文件名/ 就是目录，不加 /就是文件
Explore中 r 重命名
Explore中 d 删除
dw 剪切当前整个单词 Background
dW 剪切当前整个长标识符 context.Background()
y 复制光标所在文件的绝对地址
yy 复制当前整行(带空格和换行符)
y_ 复制当前整行(带空格)
yw 复制当前整个单词 Background
yW 复制当前整个长标识符 context.Background()
H 查看隐藏文件
<leader> + cr 重命名变量/方法
<leader> + ca Code Action，LSP提供的一些小功能，如快速修复什么的
K Hover模式打开光标所在代码的文档（:q退出）
Alt+j/k 将整行上下移动(Normal/Insert/Visual 全模式生效)
Shift + L/H 向右/左移动标签页
<leader> + xx 打开报错信息页面
Ctrl+ww 光标跳转到另外窗口
Ctrl+wj/wk 光标跳转到下面/上面的窗口
<leader> + bd 关闭光标当前所在窗口
<leader> + / 打开/关闭终端下边栏
V 整行选择

插件

lang.Markdown

  • :MarkdownPreview 执行了之后可以打开默认浏览器预览Markdown文档
  • 默认安装的render-markdown.nvim可以直接渲染Markdown，内置渲染效果
