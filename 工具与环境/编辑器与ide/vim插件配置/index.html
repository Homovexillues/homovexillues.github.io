使用**vim-plug**插件来安装和管理插件，需要将plug.vim文件复制到

  • Windwos C:\Program Files\Neovim\share\nvim\runtime\autoload
  • Linux ~/.local/share/nvim/site/autoload/plug.vim

然后在

  • Windows C:\Users\用户名\AppData\Local\nvim\
  • Linux ~/.config/nvim/init.vim

中创建init.vim文件,如果没有这个文件夹就自己创建一个

1
2
3
4
5

call plug#begin('')

Plug '插件名'

call plug#end()

然后在nvim里执行:PlugIntall即可开始安装
