Linux服务器安装Jupyter服务

在Linux服务器上安装Jupyter服务，加上Linux上安装的OneDrive服务以同步hexo源文件，以达到在浏览器上编辑hexo博客的目的

安装miniconda

用wget命令从清华源下载Miniconda3安装脚本并运行,并将conda添加到环境变量中

安装Jupyter

以conda install jupyter来安装jupyter 安装成功后，运行jupyter notebook password，会让你输入一个密码，经过确认后会生成一个哈希密码，存在/用户/.jupyter/jupyter_server_config.json里

遇到问题:

在非root用户安装了conda和jupyter之后在root用户上执行jupyter notebook --allow-root虽然成功开始了jupyter notebook服务，但是浏览器完全无法访问成功

解决问题:

竟然是因为没有以root用户安装jupyter，原因不明，conda卸载jupyter之后以root用户重新安装jupyter即可成功 主要是OneDrive文件夹同步到了root文件夹，改到普通用户文件夹太麻烦了懒得弄了（捂脸）

配置

通过运行jupyter notebook --generate-config命令在/用户/.jupyter/ 文件夹下生成一个jupyter_notebook_config.py文件，以下是一些基本配置:

# 设置可以访问的ip，默认是localhost，可以将其改为'*',表示允许任何ip访问
c.NotebookApp.ip = '*'
# 笔记本的默认打开目录
c.NotebookApp.notebook_dir='/root/hexo'
# 笔记本启动后是否打开浏览器，设置为False即可
# c.NotebookApp.open_browser=False
# 默认访问端口，可以自己修改
# c.NotebookApp.port=8888
# jupyterlab是否显示quit按钮，设为false可以免得不小心把服务停了
c.NotebookApp.quit_button = False
# 是否允许以root用户运行
c.NoatebookApp.allow_root = True

使Jupyter在服务器上一直运行

这段是我已经配置成功了在手机上编辑的

nohup jupyter notebook --allow-root & #用nohup命令使其即使ssh断开也

pip install jupyter_contrib_nbextensions # 下载中文包
jupyter contrib nbextension install --user # 安装中文包
# 此时出现问题: MoudleNotFoundError: No moudule named 'notebook.base'
# notebook库版本太高了，不兼容了，安装6.1.0版本
pip install notebook==6.1.0
# 再执行jupyter安装命令，成功
jupyter nbextension enable --py widgetsnbextension
jupyter nbextension enable --py jupyter_highlight_selected_word

Ps. jupyter_server_config.json的优先级要高于jupyter_notebook_config.py
