Linux服务器安装code-Server

工具与环境 / Linux
创建 2023-11-24 修改 2026-07-06 字数 约 200 字  阅读 预计阅读 1 分钟
标签 Linux

服务器用wget安装太慢了，手机上先下载好了用termius传上去 使用tar -xf xxx.tar.gz命令来解压gzip压缩包并进入bin文件夹，运行nohup ./code-server &即可 配置文件位于/用户/.config/code-server/config.yaml中，格式如下

1
2
3
4

bind-addr: 0.0.0.0:8080
auth: password
password: xxxxx
cert: false

即可配置密码
