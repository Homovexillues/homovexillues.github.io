Microsoft Store 安装默认位置在%LOCALAPPDATA%\Packages\<发行版包名>\

常见包名：

  • Ubuntu：CanonicalGroupLimited.Ubuntu_79rhkp1fndgsc
  • Kali：KaliLinux.54290C8133FEE_ey8k8hqnwqnmg
  • Debian：TheDebianProject.DebianGNULinux_76v4gfsz19hv4

这个命令可以立刻查看

1

Get-ChildItem "$env:LOCALAPPDATA\Packages" -Directory | ? Name -Like '*Linux*'

# 1. 查看实例名
wsl -l -v
# 假设看到  NAME      STATE           VERSION
#            Kali      Running         2

# 2. 彻底退出
wsl --shutdown

# 3. 导出为 tar（备份兼迁移）
mkdir D:\WSL
wsl --export Kali D:\WSL\kali.tar

# 4. 注销原实例（C 盘空间就释放了）
wsl --unregister Kali

# 5. 在新目录导入并重新命名
wsl --import Kali D:\WSL\Kali D:\WSL\kali.tar --version 2

# 6. 恢复默认用户（重要！否则登录后是 root）
# 先查原用户名
cd $env:USERPROFILE
wsl -d Kali -e cat /etc/passwd | findstr /B "/home"
# 假设看到 homovexillues:x:1000:1000:,,,:/home/homovexillues:/bin/zsh
# 设置回默认用户
ubuntu config --default-user homovexillues        # Ubuntu 系列
# Kali/Debian 没有官方 config 命令，用注册表法：
Set-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Lxss\$((Get-ChildItem HKCU:\Software\Microsoft\Windows\CurrentVersion\Lxss | ?{(Get-ItemProperty $_.PSPath).DistributionName -eq 'Kali'}).PSChildName)" -Name DefaultUid -Value 1000

WSL默认会创建root用户，及初始化的时候设置的root权限用户，root用户的默认密码是随机的,需要以默认创建的root权限用户执行sudo passwd root来修改密码

更新

wsl --update,这个命令可能会卡住，可以用wsl --update --web-download来从微软应用商店或者GitHub上下载
