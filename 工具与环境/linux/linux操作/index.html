Linux查看系统信息 

1

lsb_release -a

这个工具属于Linux Standard Base（LSB）的一部分。LSB 是一套为 Linux 系统制定的标准化规范，旨在提高不同 Linux 发行版之间的兼容性。

选项 功能
-a 或 --all 显示所有系统信息，包括发行版名称、版本号、描述和代号
-i 或 --id 显示发行版的标识符（如 Ubuntu、Debian）
-d 或 --description 显示发行版的详细描述
-r 或 --release 显示发行版的版本号
-c 或 --codename 显示发行版的代号（如 Ubuntu 的 focal 或 Debian 的 buster）
-s 或 --short 以简洁格式输出信息，不显示标签
-h 或 --help 显示帮助信息

Linux做NTP时间同步

编辑配置文件 /etc/chrony/chrony.conf，找到 server 行、或者添加 NTP 服务器。

1
2
3
4
5

server ntp.aliyun.com iburst
server time.windows.com iburst
server 0.pool.ntp.org iburst

server 2.pool.ntp.org iburst

启动并启用chrony服务

1
2
3

sudo systemctl enable chronyd    # 设置开机自启动
sudo systemctl start chronyd     # 启动服务
sudo systemctl status chronyd    # 查看服务状态

检查同步状态

1
2
3
4

# 列出当前所有时间源及状态
chronyc sources     
# 查看本机同步详情
chronyc tracking

输出状态中：

  • * 表示当前正用来同步的服务器
  • ^, +, - 表示候选、可能等状态 手动立即同步

# 解包
tar -xf 文件名.tar
# 打包
tar -cf 压缩包名.tar 文件或目录
# zip格式需要下载
sudo apt install zip
# 解压
unzip 文件名.zip
# 压缩
zip -r 压缩包名.zip 文件或目录
# 7z格式需要下载
sudo apt install p7zip-full
# 解压
7z x 文件名.7z
# 压缩
7z a 文件名.7z 文件名or文件夹名
# 这个命令将会将文件解压缩并删除原有压缩文件
gzip -d filename.gz 
# 如果想要保留原有压缩文件，使用:
gzip -dk filename.gz
# .tar.gz 即是用gzip压缩的.tar归档文件
# 使用该命令可以直接解压.tar.gz文件
tar -xf filename.tar.gz 
-x 从归档文件中提取文件
-f 指定归档文件的名称，后面紧跟着归档文件的名字
-v 在执行操作时显示详细信息，即输出操作流程
-z 表示文档是经过gzip压缩的，虽然大部分情况下新版本tar会自动识别，
但是万一有上手04年之前的linux的可能性呢（耸肩）
-C 指定输出文件夹
tar -xf xxx.tar.gz -C /xxx/
