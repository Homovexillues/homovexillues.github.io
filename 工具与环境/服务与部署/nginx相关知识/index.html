安装

Windows端直接官网下载可执行文件，Linux包管理器多半可以下载，下载之后位于/usr/sbin/nginx

总之，Nginx是一个多进程的软件，多个worker进程通过共享内存的方式共享数据，由Master进程统一管理，以此实现反向代理服务器的功能，隐藏请求的服务端而只向客户端暴露自己的接口，相当于一个中间层，可以用作网关，流量监控，日志等功能

        listen       5000;

        # 定义 /api/Query 的处理方式
        location = /api/Query {
            # 限制只允许 POST 方法
            limit_except POST {
                deny all;
            }
            # 代理到指定的 IP 和端口
            proxy_pass http://192.168.1.100:8080;

            # 其中$host，$remote_addr 和 $proxy_add_x_forwarded_for 是 Nginx 的内置变量

            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
