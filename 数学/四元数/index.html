四元数（Quaternions）简介

四元数是一种扩展复数的数学概念，用于表示三维空间中的旋转。它们由 威廉·哈密顿（William Rowan Hamilton） 于 1843 年发明，主要用于计算机图形学、机器人学、航空航天等领域，以避免欧拉角和旋转矩阵的局限性（如万向节锁问题）。

1. 四元数的定义

四元数是一个四维的超复数，通常表示为：

q=a+bi+cj+dk q = a + b\mathbf{i} + c\mathbf{j} + d\mathbf{k} q=a+bi+cj+dk

其中：

  • aaa 是实部（标量部分）。

  • bi+cj+dkb\mathbf{i} + c\mathbf{j} + d\mathbf{k}bi+cj+dk 是虚部（向量部分）。

  • i,j,k\mathbf{i}, \mathbf{j}, \mathbf{k}i,j,k是虚数单位，满足以下关系：

    i2=j2=k2=ijk=−1 \mathbf{i}^2 = \mathbf{j}^2 = \mathbf{k}^2 = \mathbf{i}\mathbf{j}\mathbf{k} = -1 i2=j2=k2=ijk=−1ij=k,jk=i,ki=j \mathbf{i}\mathbf{j} = \mathbf{k}, \quad \mathbf{j}\mathbf{k} = \mathbf{i}, \quad \mathbf{k}\mathbf{i} = \mathbf{j} ij=k,jk=i,ki=jji=−k,kj=−i,ik=−j \mathbf{j}\mathbf{i} = -\mathbf{k}, \quad \mathbf{k}\mathbf{j} = -\mathbf{i}, \quad \mathbf{i}\mathbf{k} = -\mathbf{j} ji=−k,kj=−i,ik=−j

四元数也可以写成向量形式：

q=[a,v] q = [a, \mathbf{v}] q=[a,v]

其中 v=(b,c,d)\mathbf{v} = (b, c, d)v=(b,c,d)是一个三维向量。

2. 四元数的性质

  1. 模长（Norm）： 四元数的模长定义为：

    ∥q∥=a2+b2+c2+d2 \|q\| = \sqrt{a^2 + b^2 + c^2 + d^2} ∥q∥=a2+b2+c2+d2​

    如果 ∥q∥=1\|q\| = 1∥q∥=1，则称 qqq 为单位四元数。

  2. 共轭四元数： 四元数的共轭定义为：

    q∗=a−bi−cj−dk q^* = a - b\mathbf{i} - c\mathbf{j} - d\mathbf{k} q∗=a−bi−cj−dk

  3. 逆四元数： 如果 qqq 是一个非零四元数，则其逆为：

    q−1=q∗∥q∥2 q^{-1} = \frac{q^*}{\|q\|^2} q−1=∥q∥2q∗​

    对于单位四元数，q−1=q∗q^{-1} = q^*q−1=q∗。

  4. 四元数乘法： 四元数乘法不满足交换律，即 q1q2≠q2q1q_1 q_2 \neq q_2 q_1q1​q2​=q2​q1​。乘法规则由虚数单位的关系决定。

3. 四元数与旋转

四元数在三维空间中的旋转表示中非常有用。一个单位四元数可以表示绕一个轴旋转一定角度。

  1. 旋转表示： 给定旋转轴 u=(ux,uy,uz)\mathbf{u} = (u_x, u_y, u_z)u=(ux​,uy​,uz​)（单位向量）和旋转角度 θ\thetaθ，对应的四元数为：

    q=cos⁡(θ2)+sin⁡(θ2)(uxi+uyj+uzk) q = \cos\left(\frac{\theta}{2}\right) + \sin\left(\frac{\theta}{2}\right)(u_x\mathbf{i} + u_y\mathbf{j} + u_z\mathbf{k}) q=cos(2θ​)+sin(2θ​)(ux​i+uy​j+uz​k)

  2. 旋转操作： 对于一个点 p=(x,y,z)\mathbf{p} = (x, y, z)p=(x,y,z)，其旋转后的点 p′\mathbf{p}'p′ 可以通过四元数乘法计算：

    p′=qpq−1 \mathbf{p}' = q \mathbf{p} q^{-1} p′=qpq−1

    其中 p\mathbf{p}p 被表示为纯四元数 0+xi+yj+zk0 + x\mathbf{i} + y\mathbf{j} + z\mathbf{k}0+xi+yj+zk。

4. 四元数的优点

  1. 避免万向节锁（Gimbal Lock）： 欧拉角在特定情况下会导致万向节锁，而四元数没有这个问题。
  2. 插值平滑： 四元数可以方便地进行球面线性插值（SLERP），用于平滑的动画过渡。
  3. 计算效率高： 与旋转矩阵相比，四元数的存储和计算更高效。

5. 四元数的应用

  1. 计算机图形学：
    • 用于表示和插值三维对象的旋转。
    • 在游戏引擎（如Unity、Unreal Engine）中广泛使用。
  2. 机器人学：
    • 用于描述机器人的姿态和运动。
  3. 航空航天：
    • 用于飞行器的姿态控制。
  4. 虚拟现实（VR）和增强现实（AR）：
    • 用于头部和手部跟踪。

7. 示例：四元数旋转

假设我们有一个点 p=(1,0,0)\mathbf{p} = (1, 0, 0)p=(1,0,0)，我们希望绕 yyy 轴旋转 90 度。

  1. 构造四元数： 旋转轴 u=(0,1,0)\mathbf{u} = (0, 1, 0)u=(0,1,0)，角度 θ=90∘\theta = 90^\circθ=90∘。

    q=cos⁡(90∘2)+sin⁡(90∘2)(0i+1j+0k)=22+22j q = \cos\left(\frac{90^\circ}{2}\right) + \sin\left(\frac{90^\circ}{2}\right)(0\mathbf{i} + 1\mathbf{j} + 0\mathbf{k}) = \frac{\sqrt{2}}{2} + \frac{\sqrt{2}}{2}\mathbf{j} q=cos(290∘​)+sin(290∘​)(0i+1j+0k)=22​​+22​​j

  2. 旋转点： 将 p\mathbf{p}p 表示为纯四元数 0+1i+0j+0k0 + 1\mathbf{i} + 0\mathbf{j} + 0\mathbf{k}0+1i+0j+0k，计算：

    p′=qpq−1 \mathbf{p}' = q \mathbf{p} q^{-1} p′=qpq−1

    结果为 p′=(0,0,1)\mathbf{p}' = (0, 0, 1)p′=(0,0,1)。

总结

四元数是一种强大的数学工具，特别适合表示和计算三维空间中的旋转。它们避免了欧拉角的局限性，同时比旋转矩阵更高效。如果你对机器人、游戏开发或计算机图形学感兴趣，四元数是一个必须掌握的概念！
