Modbus TCP/IP

标签 Modbus / TCP/IP
目录

在TCP层上又封装了一层协议，在传输数据的时候可以定义地址，变量的存储、格式

纯TCP，双方要对协议，互相对接，测试，诊断也比较麻烦

ModBus只要把地址和数据的定义告诉上位机编程人员，代码可复用

互联网传递的，实际上是数据包，这是TCP/IP族特性

基本步骤：

  1. 给我一个地址，如IPV6地址
  2. 遵守某个网络协议TCP/UDP等把数据包发送到目的地
    1. 数据报包的生成
    2. 寻址、根据IP地址寻找网络通路（可能不止一条）
    3. 需要穿透多少层路由后放弃
数据包结构：
  • MBAP Header
  • Modbus TCP Function Codes
  • Modbus Data
  • TCP/IP Packet
