数组（array）

  1. 数组中的元素在内存中处于相邻的位置

  2. 数组的长度是固定的，一旦创建之后长度是不会变的，向量和链表就会改变

  3. 数组支持随机访问，可以用a[i]访问第i个元素，时间复杂度只有O(1)，也就是常数时间，向量就能按[]访问，但是链表就不成，链表只能按照顺序访问

  4. 可以把数组中间的数删掉，这种操作很慢，而且要将后面的元素向左移，需要O(n)的时间复杂度，n为数组长度，相比之下链表的好处在于可以删除任意元素，时间复杂度只有常数

向量（vector）

  1. 向量就是把数组包了一层，里面就是个数组，特点和数组差不多
  2. 与数组一样，元素在内存中处于相邻的位置，向量也可以通过[]来访问第i个元素
  3. 向量和数组的主要区别在于大小不固定，可以自动增长
  4. 可以用push_back()函数在向量末尾添加新的元素，添加新的元素之后，向量的大小就会增长，时间复杂度为O(1)
  5. 还可以用pop_back()函数把向量最后一个元素删除掉，时间复杂度为O(1)
  6. 可以用erase()来删除中间的元素，但是平均情况下时间复杂度会是O(n)，n为后面所有的元素

// 需要#include <vector>
vector<char> v={'h','e','l','l','o'};
// 指定初始的大小
vector<char> w(100);
// 在向量的最后插入内容
v.push_back(',');
// 删除向量最后一位的内容
// 运行后向量的最后一位会空出来，back指针会指向前一个位置
v.pop_back();
// 删除中间的元素
v.erase(v.begin()+1)
// 查看向量v的大小
v.size();
// 查看向量v的容量
v.capacity(); 
cout<<w.size()<<endl; // 大小为100
cout<<w.capacity()<<endl; // 容量为100

// 在w的末尾再添加一个元素
w.push_back('a');
cout<<w.size()<<endl; // 大小变成了101
cout<<w.capacity()<<endl; // 容量变成了200

// 解释一下
// 原本向量里有个数组用来存储元素，原本数组大小为100，数组大小就是向量的容量capacity，数组已经存满了，有100个元素，因此size也是100;
// 加入一个元素之后，原本数组大小无法存储，自动添加了新的数组长度，因此此时capacity为200，size为101
// 这个过程实际上就是一个创建新数组并拷贝数据的过程，因此非常的慢，标准库的策略是一次让数组增加很多，下一次就不用再来一遍

链表（List）

  1. 想要访问一个节点，需要一个个元素的找下去，因为数据元素在内存中并不相连
  2. 链表中有一个指向开头的指针front和指向末尾的指针back，访问开头或者末尾的时间复杂度是O(1)

// 创建一个链表
// C++默认的链表是双链表，有一个指向前一个元素的指针和指向后一个元素的指针，最前面的元素指向前的指针和最后一个元素指向后的指针可以认为是指向NULL
list<char> l={'h','e','l','l','o'};
// 访问链表开头元素
l.front();
// 访问链表末尾元素
l.back();
// 历遍链表的话要使用迭代器interator
// 用此段代码定义一个迭代器
// iter指向链表的头部节点
list<char>::iterator iter=l.begin();
// 打印inter中的数据
cout<<*iter<<endl;
// 让iter指向下一个节点
iter++;
// 此时iter的内容就会是'e'
// 可以用迭代器来更改链表数据
*iter='a';
// 链表支持插入操作，可以用push_back()或push_front()
// 此操作只有常数时间复杂度
l.push_back('s');
l.push_front('s');
// 可以对链表节点进行删除，可以用pop_back()或pop_front()
// 此操作只有常数时间复杂度
l.pop_back();
l.pop_front();
// 可以对链表中间的元素进行删除和插入，
// 此操作只有常数时间复杂度
// 在链表中间插入元素
advance(iter,1);
l.insert(iter,'e');

应用场景
  • 数组
    • 需要固定长度存储数据，从创建到删除无需改变长度
  • 向量
    • 频繁访问任意元素而不是按照顺序访问，应该用向量
    • 可以快速在末尾插入和删除元素，但是在开头和中间就很慢
  • 链表
    • 在任何位置访问和修改内存
    • 但是不支持随机访问内存
