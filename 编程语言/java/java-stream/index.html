为了解放程序员操作集合（Colletction）时的生产力，其出现归功于同时期出现的Lambda表达式，极大的提高了编程效率和程序可读性。

什么是Stream？

Stream就像一个高级迭代器，但只能遍历一次，在流的过程中，队流中的元素执行一些操作。

想要操作流，首先需要有一个数据源，可以是数组或者集合。每次操作都会返回一个新的流对象，方便进行链式操作，但原有的流对象会保持不变。
