记录(record)

传统的 class 和 struct 在相等性上很让人困惑，但 record 统一了行为：基于值的比较。

var classA = new PointClass(1, 2);
var classB = new PointClass(1, 2);

Console.WriteLine(classA == classB); // True (比较的是 (1,2) 和 (1,2))
Console.WriteLine(classA.Equals(classB)); // True

var structA = new PointStruct(1, 2);
var structB = new PointStruct(1, 2);

Console.WriteLine(structA == structB); // True (比较的是 (1,2) 和 (1,2))
Console.WriteLine(structA.Equals(structB)); // True
  • 普通 class：== 比较引用，即使属性值相同也为 false。
  • 普通 struct：== 运算符默认不可用，需要重载；Equals 方法默认通过反射比较，性能差。 record 为你自动生成了基于所有属性的、高性能的 Equals、GetHashCode 和 == 运算符。

方法

扩展方法

扩展方法使你能向现有类型"添加"方法，而无需创建新的派生类型、重新编译或以其他方式修改原始类型.

扩展方法在LINQ查询操作中特别常见。

以下是关于扩展方法的关键点：

  1. **静态方法：**扩展方法必须是静态方法。
  2. **静态类：**扩展方法必须定义在静态中
  3. **第一个参数：**扩展方法的第一个参数要扩展的类型，参数前必须使用this关键字。
  4. **命名空间：**如果扩展方法定义在不同的命名空间中，那么在使用扩展方法的地方必须包含命名空间的using指令。

示例：

public static class StringExtensions
{
    public static string ToLowerFirstLetter(this string str)
    {
        if(string.IsNullOrEmpty(str)||char.IsLower(str,0))
            return str;
        
        return char.ToLowerInvariant(str[0])+str.Substring(1);
    }
}

这个例子中，定义了一个扩展方法ToLowerFirstLetter将字符串的第一个字符转换为小写。这个方法可以像实例方法一样被调用：

1
2

string s = "Hello";
s = s.ToLowerFirstLetter();//输出"hello"

尽管扩展方法看起来像是类型的实例方法，但它们实际上是静态方法的语法糖。这意味着你不能在扩展方法中访问被扩展类型的私有或受保护的成员。扩展方法只能访问它们所扩展的类型的公共成员。此外，如果类型已经有一个实例方法和一个扩展方法具有相同的签名，那么实例方法将始终被调用。扩展方法只有在实例方法不存在的情况下才会被调用。这就是扩展方法的解析规则。

关键字

using 关键字

任何C#程序中的第一条语句都是：

1

using System;

using关键字用于在程序中包含命名空间。一个程序可以包含多个using语句

using关键字通常用于实现IDisposable接口的对象，以确保它们使用完毕后能被正确地释放，如下：

1

using (var client = new HttpClient())

这是执行清理操作的一种简洁方式，特别是在处理那些需要明确释放的非托管资源或实现IDisposable接口的对象时。

当using块内的代码执行完毕后，无论正常退出还是异常退出，HttpClient实例都会自动调用Dispose方法。Dispose方法会释放与HttpClient实例相关联的所有资源，如网络链接。

访问关键字

base

base关键字用于从派生类中访问基类的成员。在执行以下操作的时候使用它：

  • 调用基类上已被其他方法重写的方法
  • 指定创建派生类实例时调用的基类构造函数

仅允许基类访问在构造函数、实例方法和实例属性访问器中进行。

在静态方法中使用base关键字将产生错误。

所访问的基类是类声明中指定的基类，如果指定class ClassB:ClassA则从ClassB访问ClassA的成员，而不考虑ClassA基类。

public class Person
{
    protected string ssn = "444-55-6666";
    protected string name = "John L. Malgraine";

    public virtual void GetInfo()
    {
        Console.WriteLine("Name: {0}", name);
        Console.WriteLine("SSN: {0}", ssn);
    }
}
class Employee : Person
{
    public string id = "ABC567EFG";
    public override void GetInfo()
    {
        // Calling the base class GetInfo method:
        base.GetInfo();
        Console.WriteLine("Employee ID: {0}", id);
    }
}

class TestClass
{
    static void Main()
    {
        Employee E = new Employee();
        E.GetInfo();
    }
}
/*
Output
Name: John L. Malgraine
SSN: 444-55-6666
Employee ID: ABC567EFG
*/

public class BaseClass
{
    int num;

    public BaseClass()
    {
        Console.WriteLine("in BaseClass()");
    }

    public BaseClass(int i)
    {
        num = i;
        Console.WriteLine("in BaseClass(int i)");
    }

    public int GetNum()
    {
        return num;
    }
}

public class DerivedClass : BaseClass
{
    // This constructor will call BaseClass.BaseClass()
    public DerivedClass() : base()
    {
    }

    // This constructor will call BaseClass.BaseClass(int i)
    public DerivedClass(int i) : base(i)
    {
    }

    static void Main()
    {
        DerivedClass md = new DerivedClass();
        DerivedClass md1 = new DerivedClass(1);
    }
}

in BaseClass()

Lambda表达式

Lambda表达式是一个匿名函数，可以用来创建委托或表达式树类型。Lambda表达式的形式为(parameters)=>expression-or-statement-block.

Lambda表达式可以在任何方法或属性的内部定义，包括在其他方法中。它的可见性（如public,private）取决于它被复制的变量或属性的可见性。如这个例子中：
