反射是特性的充分条件，特性是反射的必要条件。

特性就是tags，给属性或者方法打标签，打了标签的属性和方法会在编译的时候特殊处理。

反射可以在运行时拿到程序中的东西

与 GetType() 的区别

typeof

  • 作用：获取指定类型的元数据。

  • 特点：在编译时确定类型。

  • 示例：

    1

    Type type = typeof(string); // 获取字符串类型的元数据

GetType()

  • 作用：获取实例对象的运行时类型。

  • 特点：在运行时根据对象动态获取。

  • 示例：

    1
2
3

    string example = "Hello";
Type type = example.GetType(); // 获取实例的类型
Console.WriteLine(type); // 输出：System.String

对比总结

  • typeof 用于静态类型（不需要实例化）。
  • GetType() 用于运行时动态类型（需要具体实例）。
