SDK和Runtimes的区别是什么?

  • SDK 即 Software Development Kit,软件开发工具包

  • Runtime 即运行时环境

  • 如果需要 开发 应用程序，应安装 SDK，因为它包含了运行时环境(Runtime)和开发工具(SDK)。

  • 如果只需要 运行 已编译的应用程序，安装 Runtime 即可。

比如:

  1. JAVA
    • SDK：Java Development Kit（JDK），包含编译器（javac）、运行时环境（JRE）和开发工具。
    • Runtime：Java Runtime Environment（JRE），用于运行 Java 应用程序。
  2. Python：
    • SDK：Python 安装包通常包含解释器、标准库和开发工具。
    • Runtime：Python 解释器（如 CPython），用于运行 Python 脚本。
  3. Node.js：
    • SDK：Node.js 安装包包含 npm（包管理工具）和运行时环境。
    • Runtime：V8 引擎，用于运行 JavaScript 代码。

在Windows上安装 

1

winget install Microsoft.DotNet.SDK.9 Microsoft.DotNet.AspNetCore.9

在Linux上安装

经过多次尝试，使用给apt添加源的方式太慢了，tuna等国内镜像不包含dotnet，用snap安装位置不对且对dotnet tool的支持不好，最后发现还不如用微软官方的脚本安装

1
2
3

wget https://dot.net/v1/dotnet-install.sh -O dotnet-install.sh
chmod +x ./dotnet-install.sh
./dotnet-install.sh --version latest

安装之后如果想要用csharprepl的话要编辑.bashrc或者你自己用的shell程序，吧dotnet tool安装的工具添加到环境变量中

1

export PATH=$PATH:$HOME/.dotnet/tools
