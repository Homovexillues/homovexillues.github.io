dotnet-sdk

文件结构如下：

目录/文件 作用
dotnet 主命令行工具，是所有 .NET 命令的入口
sdk 包含安装的 SDK 版本和工具
packs 目标框架包（如 ASP.NET Core、.NET Runtime 等）
shared 共享的运行时和框架
host 托管组件和本机主机
templates 项目模板（dotnet new 使用的模板）
sdk-manifests SDK 清单文件
LICENSE.txt .NET SDK 许可证文件
ThirdPartyNotices.txt 第三方软件许可声明

Description:
  安装或使用扩展 .NET 体验的工具。

用法:
  dotnet tool [command] [options]

选项:
  -?, -h, --help  显示命令行帮助。

命令:
  install <packageId>                           安装全局或本地工具。本地工具将被添加到清单并还原。
  uninstall <PACKAGE_ID>                        卸载全局工具或本地工具。
  update <packageId>                            更新全局或本地工具。
  list <PACKAGE_ID>                             列出全局或本地安装的工具。
  run <COMMAND_NAME> <toolArguments>            运行本地工具。请注意，此命令不能用于运行全局工具。
  search <SEARCH_TERM>                          在 nuget.org 中搜索 dotnet 工具
  restore                                       还原本地工具清单中定义的工具。
  exec, execute <packageId> <commandArguments>  从源执行工具，而无需永久安装它。

Csharp Repl

一个C#版的交互终端，可以引用nuget包 安装:dotnet tool install -g csharprepl 更新:dotnet tool update -g csharprepl
