Python解释器结构

编程语言 / Python
创建 2026-09-03 修改 2026-09-03 字数 约 500 字  阅读 预计阅读 1 分钟
标签 Python / Python库

以Windows平台为例：

  • python.exe：命令行解释器入口。
  • pythonw.exe：不显示控制台窗口的解释器入口，通常用于 GUI 程序。
  • python313.dll：CPython 3.13 的核心运行库。解释器的大部分功能实际上都在这里，python.exe 只是一个较小的启动程序。
  • python3.dll：主要提供跨 Python 3.x 的稳定 ABI 接口，供部分嵌入式程序或扩展使用。
  • *.pyd：Windows 平台的 Python 原生扩展模块，本质上是特殊形式的 DLL。例如 _ssl.pyd、sqlite3.pyd 等会被 import 机制直接加载。它们通常和 Python 版本、CPU 架构绑定。
  • *.dll：Python 或扩展模块依赖的动态链接库，例如微软 C/C++ 运行库、OpenSSL、SQLite 等。
  • python313.zip：压缩后的 Python 标准库。Python 可以直接从 ZIP 中导入模块，不需要先解压。
  • *.pyc：Python 字节码，即 .py 源代码编译后的中间形式。它不是机器码，也不是加密文件，只是让解释器无需每次重新解析源码。Python 3.13 的 .pyc 通常不能直接交给其他 Python 版本使用。
  • python313._pth：嵌入式版本非常关键的模块搜索路径配置文件。
