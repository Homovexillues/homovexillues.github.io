import requests
r = requests.get('https://xxxx')
print('网页编码',r.encoding)
print('响应状态码',r.status_code)
print('字节方式响应体',r.content)
使用方法 说明
r.status_code 检测响应状态码。如果返回200，表示请求成功；如果返回的是4xx，表示客户端错误；返回5xx表示服务器错误响应
r.content 字节方式响应体，自动解码gzip和deflate编码的响应数据

定制请求头

请求头Headers提供了关于请求，响应或其它发送实体的信息。对于爬虫而言，请求头十分重要。因为请求头可以反映出一些基础信息，包括浏览器的型号，版本，或者是爬虫python版本，等等。 对于一些基础的反爬虫，就会通过头部信息来拦截爬虫

有些网站会根据头信息来判断反爬虫，没有头部信息的爬虫会被拦截拿不到任何信息。

有时候爬虫会遇到服务器长时间不返回，如果没有设置超时，爬虫就会一直等待。

在Request中有一个timeout函数，可以设置超时。

发送post请求

有时候需要发送一些编码为表单形式的数据，比如在登录的时候需要账号密码就是用post请求发送的。如果用get请求密码就会显示在URL中，这样极其不安全。
