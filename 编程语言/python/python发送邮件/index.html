* * * * * 要执行的命令
第一个*代表分钟(0-59)
第二个*代表小时(0-23)
第三个*代表一个月中的第几天(1-31)
第四个*代表月份(1-12)
第五个*代表一个星期中的第几天(0-7,其中0和7都代表星期日)

如果想让python每天早上8点的第0分钟运行脚本
0 8 * * * /usr/bin/python3 /path/script.py
注意/usr/bin/python是python3解释器的正确路径，可以在终端输入which python来查找python解释器的路径
