进制转换

描述

写出一个程序，接受一个十六进制的数，输出该数值的十进制表示。

数据范围：保证结果在 1≤n≤2^31−1

输入描述：

输入一个十六进制的数值字符串。

输出描述：

输出该数值的十进制字符串。不同组的测试用例用\n隔开。

示例1

输入：

0xAA

输出：

170

你可以假设每种输入只会对应一个答案。但是，数组中同一个元素在答案里不能重复出现。

你可以按任意顺序返回答案。

class Solution:
    def twoSum(self,nums,target):
        lens = len(nums)#数组长度
        for i in range(1,lens):#i在数组内遍历，从第二个数开始
            if(target-nums[i]) in nums:#如果另一个数在数组里
                j = nums.index(target-nums[i])#定位这个数的下角标
                if(j!=i):#这个数不能是i
                    break

        return [j,i]

            return 1
        return self.jumpFloor(number-1)+self.jumpFloor(number-2)

整数与IP地址间的转换

描述

原理：ip地址的每段可以看成是一个0-255的整数，把每段拆分成一个二进制形式组合起来，然后把这个二进制数转变成 一个长整数。 举例：一个ip地址为10.0.3.193 每段数字 相对应的二进制数 10 00001010 0 00000000 3 00000011 193 11000001

组合起来即为：00001010 00000000 00000011 11000001,转换为10进制数就是：167773121，即该IP地址转换后的数字就是它了。

数据范围：保证输入的是合法的 IP 序列

输入描述：

输入 1 输入IP地址 2 输入10进制型的IP地址

输出描述：

输出 1 输出转换成10进制的IP地址 2 输出转换后的IP地址

示例1

输入：

1
2

10.0.3.193
167969729

输出：

1
2

167773121

    try:# 用于尝试执行可能会引发异常的代码块
        ip = input()#从用户这里获取一个字符串输入，ip地址
        num = input()#从用户这里获取字符串输入，二进制数
    except:
        break

    else:#如果try代码块中代码执行成功，那么将执行else代码块中的代码
        ip_list = ip.split('.')#将输入的IP地址字符串按'.'分割，得到一个包含四个字符串的列表
        ip2num = str()#初始化一个空字符串，用于存储转换后的二进制数
        for i in ip_list:#遍历其中的每个元素
            a = bin(int(i,10))[2:]#将ip地址的一部分从十进制转换为二进制
            a = '0'*(8-len(a)) + a if len(a)<8 else a#如果二进制数长度小于8，应该在签名添加足够的0，使其长度达到8
            ip2num += a#将转换后的二进制数添加到ip2num结尾
        print(int(ip2num,2))#将ip2num从二进制转化为十进制
        # num to ip
        num2ip = []#初始化一个空列表，用于存储转换后的IP地址
        num2 = bin(int(num,10))[2:]#将输入的十进制数转换为二进制数
        num2 = '0'*(32-len(num2))+num2 if len(num2)<32 else num2
        #如果二进制数长度小于32，那么在签名添加0
        for i in range(4):#进行四次循环，每次循环处理二进制数的一部分
            b = num2[8*i:8*i+8]
            b = str(int(b,2))#将而仅是数的这一部分从二进制转换为十进制
            num2ip.append(b)
        print('.'.join(num2ip))#将num2ip列表中的元素使用.连接起来，形成字符串，最后打印出来

符号运算/求分数计算结果

给定一个表达式，求其分数计算结果。

表达式的限制如下:

1.所有的输入数字皆为 正整数 (包括 0)

2.仅支持四则运算 (+ - */) 和括号

3.结果为整数或分数，分数必须化为最简格式 (比如 6,3/4,7/8,90/7)

4.除数可能为 0，如果遇到这种情况，直接输出“ERROR

5.输入和最终计算结果中的数字都不会超出整型范围 用例输入一定合法，不会出现括号匹配的情况。

输入描述

字符串格式的表达式，仅支持 + - */，数字可能超过两位，可能带有空格，没有负数长度小于 200 个字符。

输出描述

表达式结果，以最简格式表达

如果结果为整数，那么直接输出整数

如果结果为负数，那么分子分母不可再约分，可以为假分数，不可表达为带分数结果可能是负数，符号放在前面

示例1 输入 1 + 5 * 7 / 8 输出： 43/8 示例2 输入 1 / （0 - 5） 输出： -1/5 示例3 输入 1 * (3 * 4 / (8 - (7 + 0))) 输出： 12

import functools
import sys
import copy
import re
import math
import queue

nums = [] #存储分数的栈。每个分数都表示为一个长度为2的列表，其中第一个元素是分子，第二个元素是分母。
operations = [] #存储运算符的栈

# 最大公约数
def gcd(a,b):
    if(a%b==0):
        return b
    else:
        return gcd(b,a%b)#用递归来找到最大公约数
    
# 用于执行运算符操作。从nums和operations中
def eval_op():
    global nums,operations
    nums1 = nums.pop() #取出最后一个操作数
    nums2 = nums.pop() #取数倒数第二个操作数
    x = operations.pop() #取出最后一个操作符
    result = [0,0] #初始化结果
    if(x == '*' or x == '+' or x == '-'):
        result[0] = nums2[0] * nums1[0] #如果是加减乘，则分子相乘
    else:
        result[0] = nums2[0] * nums1[1] #如果是除，则分子乘以分母

    sum_a = nums2[1] * nums1[0]
    sum_b = nums1[1] * nums2[0]
    if(x == '*'):
        result[1] = nums2[1] * nums1[1] #如果是乘，则分母相乘
    elif (x == '+'):
        result[1] = sum_a + sum_b #如果是加，则分子相加
    elif (x == '-'):
        result[1] = sum_a - sum_b #如果是减，则分子相减
    else:
        result[1] = nums2[1] * nums1[0] #如果是除，则分母乘以分子

    nums.append(result) #将结果添加到操作数列表

#获取操作符的优先级
def get_priority(input_char):
    if(input_char == '+' or input_char == '-'):
        return 0 #加减的优先级为0
    else:
        return 1 #乘除的优先级为1
    

input_str = input()
nums = []
operations = []
length = len(input_str)
current = "" #初始化当前字符
i=0#初始化索引
while (i<length):#遍历表达式
    if(input_str[i].isdigit()):#判断当前字符是否是数字
        while True:
            if(not input_str[i].isdigit()):#如果当前字符不是数字，跳出循环
                break
            current += input_str[i] #将当前字符添加到当前数字
            if(i+1 >= length): #如果索引超出范围，则跳出循环
                break
            i+=1#索引加一
        nums.append([1,int(current)])#将当前数字添加到操作数列表
        current = ""#清空当前数字
    elif (input_str[i] == '('):#如果当前字符是左括号
        operations.append(input_str[i])#将左括号添加到操作符列表
    elif (input_str[i] == ')'):#如果当前字符是右括号
        while(operations[0] != '('): #如果操作符列表的最后一个元素不是左括号
            eval_op() #执行操作符
        operations.pop(0)#删除操作符列表的最后一个元素（左括号）
    elif(input_str[i] == ' '):#如果当前字符是空格
        i+=1 #索引加1
        continue #跳过当前循环
    else: #如果当前字符是操作符
        while (len(operations)>0 and operations[0] != '(' and get_priority(input_str[i]) <= get_priority(operations[0])): #如果操作符列表不为空，且最后一个元素不是左括号，且当前操作符的优先级小于等于最后一个操作符的优先级
            eval_op() #执行操作符
        operations.append(input_str[i]) #将当前操作符添加到操作符列表
    i+=1 #索引加一

while True:
    if(len(nums)<=1): #如果操作数列表的长度小于等于1
        break #跳出循环
    else:
        eval_op() #执行操作符

result = nums[0]#获取结果
if(result[0]==0):#如果分子为0
    print("ERROR")#输出错误
else:
    up = gcd(result[0],result[1]) #计算分子和分母的最大公约数
    result[0] /= up #分子除以最大公约数
    result[1] /= up #分母除以最大公约数
    output_str = "" #初始化输出字符串
    if(result[0] * result[1]<0):#如果结果为负数
        output_str += "-"#在输出字符串前添加负号
    if(abs(result[0]) == 1):#如果分子绝对值为1
        print(output_str+str(result[1]))#输出分母
    else:
        print(output_str+str(abs(int(result[1]))) + "/" + str(abs(int(result[0]))))#输出分数
