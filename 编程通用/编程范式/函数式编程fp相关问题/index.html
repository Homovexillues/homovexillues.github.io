为啥叫不可变数据，但是struct和record还可以通过with来修改已经实例化了的实例？

好问题！这是一个常见的误解。让我解释一下"不可变"的真正含义：

“不可变"的真实含义

关键点：with 表达式不是修改原实例，而是创建了一个新实例！

3

public record Person(string Name, int Age);

var person1 = new Person("Alice", 30);
var person2 = person1 with { Age = 31 };

Console.WriteLine(person1.Age); // 30 - 原实例未改变！
Console.WriteLine(person2.Age); // 31 - 这是全新的实例

Console.WriteLine(ReferenceEquals(person1, person2)); // False - 不同对象

with 表达式的底层实现

编译器会将 with 表达式转换为类似这样的代码：

1
2
3
4
5

// 你写的代码：
var person2 = person1 with { Age = 31 };

// 编译器生成的等效代码（简化版）：
var person2 = new Person(person1.Name, 31); // 创建新对象，复制未改变的属性

实际上 record 会生成一个拷贝构造函数：

1
2
3
4
5
6
7

9

// 编译器为 record 自动生成：
protected Person(Person original)
{
    this.Name = original.Name;
    this.Age = original.Age;
}

// with 表达式使用这个构造函数：
var person2 = new Person(person1) { Age = 31 };

public record BankAccount(string Owner, decimal Balance);

var account1 = new BankAccount("Alice", 1000m);

// 假设这是一个"存款"操作
var account2 = account1 with { Balance = account1.Balance + 500 };

Console.WriteLine($"账户1余额: {account1.Balance}"); // 1000 - 未改变！
Console.WriteLine($"账户2余额: {account2.Balance}"); // 1500

// 这在多线程环境中非常安全：
Task.Run(() => 
{
    // 线程A 读取 account1
    Console.WriteLine(account1.Balance); // 始终是 1000
});

Task.Run(() => 
{
    // 线程B 创建新版本
    var account3 = account1 with { Balance = 2000 };
    // 不会影响线程A看到的 account1
});

1. 线程安全

public record GameState(int Score, int Level);

private GameState _currentState = new GameState(0, 1);

// 多个线程可以安全地读取
public GameState GetState() => _currentState;

// 更新时创建新实例（原子操作）
public void UpdateScore(int points)
{
    GameState oldState, newState;
    do
    {
        oldState = _currentState;
        newState = oldState with { Score = oldState.Score + points };
    } while (Interlocked.CompareExchange(ref _currentState, newState, oldState) != oldState);
}

public class AGVStateHistory
{
    private readonly Stack<AGVState> _history = new();
    
    public AGVState Current => _history.Peek();
    
    public void UpdateState(Func<AGVState, AGVState> update)
    {
        var newState = update(Current); // 创建新状态
        _history.Push(newState);        // 保留旧状态
    }
    
    public void Undo()
    {
        if (_history.Count > 1)
            _history.Pop(); // 可以回到之前的状态！
    }
}

// 使用：
var history = new AGVStateHistory();
history.UpdateState(state => state with { Position = new Position(10, 20) });
history.UpdateState(state => state with { Position = new Position(15, 25) });
history.Undo(); // 回到 (10, 20)

// 使用 init 而不是 set
public record ImmutablePerson
{
    public string Name { get; init; }
    public int Age { get; init; }
}

var person = new ImmutablePerson { Name = "Alice", Age = 30 };
// person.Age = 31; // 编译错误！
var updated = person with { Age = 31 }; // 只能这样创建新实例

// 或者使用位置记录（推荐）
public record Person(string Name, int Age); // 属性自动是 init-only

总结

操作 是否修改原对象 是否创建新对象 内存地址
person.Age = 31 (可变类) ✅ 是 ❌ 否 相同
person with { Age = 31 } (record) ❌ 否 ✅ 是 不同

不可变的本质：一旦对象创建，它的内容永远不会改变。with 表达式只是语法糖，让你更方便地基于旧对象创建新对象。

这就像字符串（string）在 C# 中也是不可变的：

1
2
3

string str1 = "Hello";
string str2 = str1 + " World"; // 创建新字符串，str1 未改变
Console.WriteLine(str1); // 仍然是 "Hello"
