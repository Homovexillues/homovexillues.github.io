安装

Linux

Ubuntu24.04下可以直接从apt的默认源安装

1

sudo apt install redis-server

Windows

Windows上想用的话要么是WSL套一层，要么是Docker Desktop（也要依赖WSL）

1

docker run -d -p 6379:6379 redis

# 常用命令
SET key "value"       # 设置键值
GET key               # 获取值
DEL key               # 删除
LPUSH list "item"     # 列表推入
LRANGE list 0 -1      # 获取列表全部
PUBLISH channel "msg" # 发布消息（聊天室核心）
SUBSCRIBE channel     # 订阅频道

原理

  • 本质上来说，Redis的核心数据结果就是一个内存中的key-value哈希表
  • Redis用单线程事件循环处理所有命令，串行化了所有操作，因此天然不需要互斥锁
  • Redis实现了一个TCP服务器，客户端通过RESP（Redis Serialization Protocol）这个极简的文本协议通信

一些特性：

  • 支持多种数据结构：String、List、Set、Sorted Set、Hash、Stream 等
  • 持久化 — 可选 RDB（快照）或 AOF（追加日志），不只是纯内存
  • Pub/Sub — 发布订阅，适合聊天室这种场景
  • 过期机制 — 键可以设 TTL 自动删除
  • 原子操作 — 单线程保证每个命令都是原子的，不会有竞态

为什么快：

  1. 全内存操作，不走磁盘
  2. 单线程无锁，无上下文切换开销
  3. I/O 多路复用（epoll/kqueue），一个线程处理上万连接
  4. RESP 协议极简，解析成本低
