安装

由于Sqlite数据库本质上就是个文件，所以这里安装的都是在不同平台处理SQLite数据库的工具

Linux 

1

sudo apt install sqlite3

控制

查看此库有哪些表

这条语句会返回当前数据库中所有用户创建的表的名称。

1

SELECT name FROM sqlite_master WHERE type='table' ORDER BY name;

不经筛选的话则返回包括系统表的所有表

1

SELECT name FROM sqlite_master;
