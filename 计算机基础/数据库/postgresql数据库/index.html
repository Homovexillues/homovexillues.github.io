介绍

数据页

pg的数据表叫堆表文件，是磁盘上一个数字命名的没有后缀名的文件这个数字代表这张数据表在数据库里的ID，又叫relfileNode,数据表越大，堆表文件也就越大，而当堆表文件超过1GB时，会自动分割为多个文件 堆表文件里会将数据拆分成一个一个数据页来存储，每页8KB，这样只需要读取磁盘里的页就可以，比读写整个表要快很多

安装

Linux

在线安装

linux下如果apt能找到直接安装

1

sudo apt install postgresql

如果找不到加个源再装,官方文档地址:PostgreSQL: Linux downloads (Ubuntu)

# Import the repository signing key:
sudo apt install curl ca-certificates  
sudo install -d /usr/share/postgresql-common/pgdg  
sudo curl -o /usr/share/postgresql-common/pgdg/apt.postgresql.org.asc --fail https://www.postgresql.org/media/keys/ACCC4CF8.asc  
# Create the repository configuration file:
# 这里是个bash语法，如果用的别的shell要注意
. /etc/os-release  
sudo sh -c "echo 'deb [signed-by=/usr/share/postgresql-common/pgdg/apt.postgresql.org.asc] https://apt.postgresql.org/pub/repos/apt $VERSION_CODENAME-pgdg main' > /etc/apt/sources.list.d/pgdg.list"  
sudo apt update

装完了之后会自动注册成systemctl服务

1

sudo systemctl status postgresql

且会自动配置开机自启动

1
2

sudo systemctl is-enabled posgresql
>>> enabled

离线安装

可以编译源码安装，也可以.deb包安装

deb包安装

大致原理是下载apt-rdepends工具分析包的依赖，过滤掉虚拟包，然后用apt-get download下载所有.deb包，传输到离线设备上用dpkg -i *.deb命令来离线安装就好

配置

配置文件

修改postgresql.conf

Linux下位置在：/etc/postgresql/15/main/postgresql.conf

Windows下位置在:"C:\Program Files\PostgreSQL\17\data\postgresql.conf"

1
2
3

listen_addresses = '*'  # 允许所有IP连接 localhost则本地
port = 5432            # 默认端口
max_connections = 100   # 根据硬件调整

修改同文件夹下pg_hba.conf

1
2

# 允许所有IP通过密码访问
host    all             all             0.0.0.0/0               scram-sha-256

重启服务生效

登录 
1

psql -U myuser -d mydb -h 127.0.0.1 -p 5432

  • -d数据库名
  • -h主机地址
  • -p端口号

命令 说明 示例输出片段
\l 列出所有数据库 `mydb \ myuser \ UTF8`
\c dbname 切换数据库 You are now connected to database "mydb"
\dt 列出当前数据库的所有表 `public \ users \ table`

基础数据库 

1
2
3

select oid,datname,datistemplate
from pg_database
order by oid;
1
2
3
4
5

 oid | datname  | datistemplate
-----+----------+---------------
   1 | template1| t
   4 | template0| t
   5 | postgres | f
OID 数据库名 作用
1 template1 真正的“模板库”。以后你执行 CREATE DATABASE 时，PG 会直接把 template1 复制一份成新库。
4 template0 只读备胎模板，内容与 template1 几乎一样，但编码/区域设置不可改，用于“干净”重建或需要不同编码时。
5 postgres 默认给你连接的管理库，啥也没有，纯粹方便管理员连上来再建别的库。

PostgreSQL 自己必须存在的三个系统数据库，在执行 initdb 时就自动生成，永远不能删掉
